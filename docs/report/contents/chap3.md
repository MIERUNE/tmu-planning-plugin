# 接続する API の情報

このプラグインでは、以下の API に接続してデータを取得・可視化しています。

## 国土地理院ベクトルタイル

**API の提供元**  
国土地理院 地理院タイル（ベクトルタイル提供実験）

**API サイト**  
https://maps.gsi.go.jp/development/vt.html

**利用データ**

- 水域
- 高速道路
- 主要道路
- 建物ポリゴン

**クレジット**  
出典：国土地理院ウェブサイト  
地理院タイル（ベクトルタイル）を加工して作成

## 国土交通データプラットフォーム

**API の提供元**  
国土交通省 国土交通データプラットフォーム

**API サイト**  
https://data-platform.mlit.go.jp/

**利用データ**

- 行政区域（3クラス・5クラス・6クラス分類）

**データの出典（3クラス・5クラス）**  
大澤 剛士, 山野 博哉, 小笠原 奨悟「土地利用基本計画から推進しやすいグリーンインフラのタイプを検討する」（https://doi.org/10.3825/ece.24-00022）

**データの出典（6クラス）**  
Developing national-scale basic guideline on flood-adaptation strategies under climate change using probabilistic and deterministic factors. Water Research 282: 123723 (2025)  
著者：Osawa T, Sakurai G, Wakai A  
DOI：https://doi.org/10.1016/j.watres.2025.123723

## 不動産情報ライブラリ

**API の提供元**  
国土交通省 不動産情報ライブラリ

**API サイト**  
https://www.reinfolib.mlit.go.jp/

**利用データ**

- 人口集中地区（DID）
- 都市計画区域/区域区分
- 用途地域
- 立地適正化計画
- 地区計画
- 高度利用地区
- 自然公園地域

**クレジット**  
このサービスは、国土交通省の不動産情報ライブラリの API 機能を使用していますが、提供情報の最新性、正確性、完全性等が保証されたものではありません

## 海しる（海洋状況表示システム）

**API の提供元**  
海上保安庁 海洋状況表示システム（海しる）

**API サイト**  
https://www.msil.go.jp/

**利用データ**

- 海岸線
- 港湾区域
- 漁港区域

**クレジット**  
このサービスは、海しる API を利用して取得した情報をもとに作成しているが、サービスの内容は海上保安庁によって保証されたものではない

## e-Stat（政府統計の総合窓口）

**API の提供元**  
政府統計の総合窓口（e-Stat）

**API サイト**  
https://www.e-stat.go.jp/

**利用データ**

- 人口メッシュ（3 次メッシュ）
- 人口メッシュ（4 次メッシュ）

**クレジット**  
このサービスは、政府統計総合窓口(e-Stat)の API 機能を使用していますが、サービスの内容は国によって保証されたものではありません。

## ハザードマップポータルサイト

**API の提供元**  
国土交通省 ハザードマップポータルサイト

**API サイト**  
https://disaportal.gsi.go.jp/

**利用データ**

- 洪水浸水想定区域（想定最大規模）

**クレジット**  
「ハザードマップポータルサイト」（https://disaportal.gsi.go.jp/）を加工して作成

## 環境ジオポータル

**API の提供元**  
環境省 生物多様性センター（環境ジオポータル）

**API サイト**  
https://geoportal.env.go.jp/

**利用データ**

- 現存植生図2024

**クレジット**  
出典：環境省生物多様性センター「現存植生図2024（1/25,000植生図）」（https://geoportal.env.go.jp/）  
このサービスは、環境ジオポータルのデータを加工して作成しています。  
出典：環境省生物多様性センター「現存植生図2024スタイル設定ファイル」（CC BY 4.0）（https://geoportal.env.go.jp/datasets/368329d069ab4e70a0b1938eb050ad07）
